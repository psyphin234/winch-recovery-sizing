# Winch Planning and Sizing

How much pull it takes to winch a stuck 4x4 out, what double and triple line pulls do, how your winch copes as rope piles onto the drum, the current it draws on the way, and the block and shackle ratings to match. You set it up on animated pictures.

Every number comes from a published recovery method (I4WDTA), a manufacturer (WARN, Crosby), engineering practice (LEEA) or plain physics, and the Sources page shows each one with the words it comes from. Where nobody publishes a figure, the page says so.

Plain HTML, CSS and JavaScript: open `index.html` in a browser. Nothing you enter leaves your browser.
